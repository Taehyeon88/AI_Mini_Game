# 11. 인트로 화면 (Intro / Title)

> 게임 시작 전 첫 화면. 토이라 **최소**로. 챕터 **4-9**(UI)에서 만든다.
> 상태 흐름은 §12(Game Flow)의 `Title` 상태와 연결.

## 구성 (최소)
- **타이틀 텍스트** (게임 이름 — 임시, 추후 확정)
- **시작 안내**: "Space로 시작" (또는 클릭)
- (선택) **조작 안내 한 줄**: WASD 이동 · 무기 자동 · ESC 일시정지
- 배경: 인게임 바닥 타일 + 캐릭터 1컷 정도면 충분 (정적)

## 동작
- `Title` 상태에서 표시. **Space** 입력 → `Playing`으로 전환(§12).
- 결과/게임오버 화면의 "다시 시작"도 `Title` 또는 바로 `Playing`으로 복귀(§12 흐름).
- BGM은 §10 정책 따름.

## 비스코프
- 캐릭터 선택·옵션 메뉴·세팅 화면 (game-design §8 비스코프 그대로).
