# 6. 경험치 & 레벨업 (EXP & Level)

**EXP gem**
- 적 처치 위치에 드랍 (IPickup 구현, **gem 프리팹 1종**을 ObjectPool에서 꺼냄)
- 플레이어 픽업 반경(2.3) 안에 들어오면 **자석 흡수**: 매 프레임 플레이어로 `Vector2.MoveTowards`(흡수 속도 예: 18.8 u/s, 가까울수록 가속 선택), 접촉 시 `OnPickup`으로 EXP 가산 후 풀 반환
- 흡수 시 EXP 가산

**레벨 곡선** — `누적 EXP` = 해당 레벨 **도달까지 총합**, `증분` = 직전 레벨업에 필요한 EXP(= 표의 차분 = `ExpToNext`)
| 도달 레벨 | 누적 EXP | 증분(ExpToNext) |
|------|----------|------|
| L2 | 5 | 5 |
| L3 | 12 | 7 |
| L4 | 22 | 10 |
| L5 | 35 | 13 |
| L6 | 50 | 15 |
| **L7+** | 직전 + 증분 | **증분 = 직전 증분 + 5** (→ 20·25·30…) |

- 레벨업 판정: 보유 EXP가 다음 레벨 누적값 이상 → 레벨업(초과분 이월).
- `ExpToNext` = 현재 레벨의 증분. EXP바 fill = (현재 레벨 내 EXP) / `ExpToNext`.

**레벨업 처리**
1. 임계 도달 → `GameManager.ChangeState(LevelUpPaused)` (Time.timeScale = 0)
2. 업그레이드 선택 UI 표시 (3택)
3. 플레이어가 1개 선택 → 적용
4. `ChangeState(Playing)` → 게임 재개

**연속 레벨업 큐잉** — 한 번에 임계를 2단계 이상 넘기거나 일시정지 중 추가로 도달하면 **남은 레벨업을 큐에 보유**, 패널이 닫힐 때 큐가 비지 않았으면 즉시 다음 3택 패널 재호출. (초반 임계가 낮아 1프레임 2레벨 빈발 → 누락/락 방지)
