# 8. 웨이브 시스템 (Wave / Spawner)

`EnemySpawner`가 시간 기반으로 스폰 호출.

| 시간(초) | 스폰 간격 | 동시 최대 | 적 풀 | 비고 |
|----------|-----------|-----------|-------|------|
| 0~30 | 1.3초 | 14 | 쥐 | 밸런스 조정(2026-09-24): 1.5초→1.3초, 12→14 |
| 30~75 | 0.9초 | 22 | 쥐, 박쥐 | 밸런스 조정(2026-09-24): 2026-09-23의 스파이크 완화(20→16)를 되돌리고 20→22로 상향 (전반 난이도 상향 요청) |
| 75~120 | 0.6초 | 38 | 쥐, 박쥐, 사이클롭스 | 밸런스 조정(2026-09-24): 0.7초→0.6초, 35→38 |
| **120** | — | — | — | **보스(네크로맨서) 등장** (BossSpawner 단발) — 미구현 |
| 120~180 | 0.5초 | 45 | 전체 잡몹 + 보스 | 밸런스 조정(2026-09-24): 0.6초→0.5초. 보스 미구현 기간엔 잡몹 전체풀(쥐+박쥐+사이클롭스)만 적용 |

- 스폰 위치: 카메라 뷰포트 밖 무작위 가장자리
- 화면 밖 멀리(31 units 이상) 가면 풀로 반환
- **보스**: `BossSpawner`(단발)가 120초에 한 번 호출. 풀링 X, 단일 인스턴스
- **유령**: 웨이브 표에 없음 — 보스가 5초마다 직접 소환(§4). 일반 잡몹 스포너와 무관
