# 9. UI

> 해상도 기준은 §3(해상도·화면) 참고. **Canvas Scaler는 캔버스별로 다름** (실제 씬 기준):
> - **HUD Canvas**: `Scale With Screen Size`, Reference **640×360**, Match 0.5
> - **UpgradeUI 전용 Canvas**: Reference **1920×1080**, Match 0.5 (아래 "프리팹 구조" 참고 — 세로 1080×1920 실기기에서도 카드 270×380 등 px 수치가 그대로 유지되도록 계산된 값, 임의 변경 금지)

**폰트 (TMP — Dynamic, 사전 베이크 불필요)**
- 배포 ttf 3종에서 각각 TMP Font Asset 생성(Create ▸ TextMeshPro ▸ Font Asset), **Atlas Population Mode = Dynamic** — 한글 글리프가 쓰는 만큼 자동 추가(에디터 작업, 4-9). TMP Essentials 임포트 선행.
- 용도: **DNFBitBitv2** = 타이틀·타이머 숫자 / **Maplestory Bold** = 카드 제목·버튼 / **Maplestory Light** = 설명·조작 안내.

**UI 스프라이트 배정 (배포 자산 ↔ 용도)**
- 업그레이드 카드 아이콘 = `icon1~11` (카드 10종 1:1 + 예비 1 — 번호 배정은 자유, `UpgradeData.icon`에 연결)
- 패널 프레임 = `panel-border-011/014/015` (레벨업 카드 · 결과 패널 · 일시정지 등 자유 배정. 9-slice 보더 설정 후 Image Type=Sliced)
- 바 = `hp_bar_player`+`hp_fill_player` / `hp_bar_boss`+`hp_fill_boss` / `exp_fill`(**EXP는 테두리 없이 fill 단독** — 의도). fill류는 Image Type=Filled(Horizontal)

**HUD (인게임 표시)**
- 상단 중앙: 타이머 (남은 시간, mm:ss) + 처치 수 — 하나의 검은 배경 패널(α 120) 위에 배치
- 좌상단: HP바 — 상단 패널 바로 아래
- 좌하단 (아래→위): ①레벨 숫자 + EXP바 — 화면 최하단에 붙임 / ②무기(단검·도끼) 아이콘 + 현재 공격력 수치 — EXP바 바로 위. 미보유 무기는 숨김. `IWeapon.CurrentDamage` 폴링
- **하단 (2:00 이후만)**: 보스 HP바 — 화면 폭 전체, 보스 등장 시 슬라이드 인, 처치 시 슬라이드 아웃 → **4-8(보스 챕터)에서 구현**

**레벨업 카드 UI**
- 일시정지(`GameState.LevelUpPaused`) 시 화면 중앙에 반투명 딤 배경 + 카드 3개 가로 배치
- 카드: 아이콘 + 이름 + 한 줄 설명
- 마우스 클릭으로 선택 (키보드 1/2/3 → `LevelUpPanel.Select(int)` 로 연결하는 자리만 마련됨 — 입력 배선은 미구현)

**프리팹 구조 — `Assets/Prefabs/UpgradeUI.prefab`** (이 구조가 정본. 씬엔 이 프리팹 인스턴스 1개 배치, `_GameManagers`가 아닌 자체 Canvas)

```
UpgradeUI                Canvas(ScreenSpaceOverlay, SortingOrder 10) + CanvasScaler(1920×1080, Match 0.5) + GraphicRaycaster
└─ LevelUpPanel          LevelUpPanel.cs (Singleton) — RectTransform 전체 화면 stretch
   └─ PanelRoot          Image(검정, α≈0.47 ≒ 120/255, RaycastTarget off) — 딤 배경 겸 "표시 ON/OFF" 토글 대상, 전체 stretch
      ├─ Card1            Button + UpgradeCardUI   (중앙 anchor, anchoredPos x = -310)
      ├─ Card2            Button + UpgradeCardUI   (중앙 anchor, anchoredPos x =    0)
      └─ Card3            Button + UpgradeCardUI   (중앙 anchor, anchoredPos x = +310)
```

각 `CardN` (RectTransform 270×380, anchor 중앙) 의 자식 — **위→아래 = 렌더 뒤→앞(겹침) 순서**:

```
CardN
├─ Card_BG        Image(흰색, 스프라이트 없음)                     ← Button.targetGraphic(클릭 틴트 대상), 카드 전체 stretch
├─ Card_Name_BG   Image(#3E2530, 어두운 자주)                     상단 이름 영역 배경, stretch
├─ Card_Desc_BG   Image(흰색)                                     하단 설명 영역 배경, stretch
├─ Card_border    Image(panel-border-015, Type=Sliced, #3E2530)   카드 전체 stretch — 9슬라이스 테두리 프레임
├─ Icon           Image(아이콘 스프라이트)                         상단중앙 anchor, pos(0, -70), 100×100
├─ NameText       TMP(Maplestory Bold, 28, 흰색, 가운데정렬)        가로 stretch, 카드 상단
└─ DescText       TMP(Maplestory Light, 22, #3C2531, 가운데·줄바꿈)  가로 stretch, 카드 하단
```

**스크립트 바인딩 (인스펙터 연결)**
- `LevelUpPanel` (`LevelUpPanel` 오브젝트): `_panelRoot` → `PanelRoot`, `_cards[3]` → `Card1/2/3` 의 `UpgradeCardUI`
- `UpgradeCardUI` (각 카드): `_icon` → 자식 `Icon`, `_nameText` → `NameText`, `_descText` → `DescText`, `_button` → 자기 `Button`

**동작**
- `LevelUpPaused` 진입 → `PanelRoot` 활성, `UpgradeCardSelector.Shuffle3(player)` 로 3택을 뽑아 각 카드에 `Bind(data, onSelect)`
- 카드 클릭 → `UpgradeService.Apply(data, player)` 적용 후 `GameState.Playing` 복귀
- `data == null` 인 카드는 `Bind` 에서 자동 비활성 (3택 미만 상황 대비)
- Icon 스프라이트 · 이름 · 설명 텍스트는 런타임 `Bind` 가 `UpgradeData` 로 채움 — 프리팹에 박힌 `icon10` · 샘플 텍스트는 플레이스홀더

**레이아웃 수치**
- 카드 270×380, 가로 중심 간격 310px (카드 사이 여백 40px), 3장 중앙 정렬
- Icon 100×100, 카드 상단중앙(y = -70)

**결과 화면 (클리어/게임오버)**
- 표시: 생존 시간, 처치 수, 최종 레벨
- "다시 시작" 버튼

**시작/인트로 화면** → §11(인트로 화면) 참고 (Title 상태, "Space로 시작").
