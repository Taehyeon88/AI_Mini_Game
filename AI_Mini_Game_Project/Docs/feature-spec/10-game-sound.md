# 10. 게임 사운드 (Sound)

> 강사 제공 SFX/BGM (`_GameKit/Sounds/`). 게임플레이가 아니라 폴리싱 — 챕터 **4-10**에서 한 번에 붙인다.
> 톤: game-design §7(가볍고 빠른 액션, 어둡지 않게).

## SFX (트리거 ↔ 파일 매핑)
| 트리거 | 파일 | 비고 |
|--------|------|------|
| 공격 발사 (플레이어 무기) | `fire1.mp3` | 무기별 같은 SFX 재사용 (빈도 높음 → 볼륨 낮게) |
| 보스 마법탄 발사 | `fire2.mp3` | 임시 배정 — fire1과 맞바꿔도 무방 |
| 피격 | `impact.mp3` | 플레이어 피격 시 (적 피격은 생략) |
| EXP 픽업 | `pick.mp3` | 짧고 가벼운 톤 |
| 레벨업 | `levelup.mp3` | 약간 강조 (3택 패널 등장과 동기) |
| 게임오버 | `gameover.mp3` | 1회 |
| 클리어(승리) | `clear.mp3` | 1회 |
| 보스 등장 | (전용 SFX 없음) | **boss_bgm 전환으로 갈음** |

- 동시 다발(공격·픽업)은 **볼륨/피치 살짝 랜덤**으로 단조로움 방지(선택).
- 오디오는 단순 `AudioSource.PlayOneShot` 수준. 전용 매니저는 토이 범위 — 필요하면 가벼운 `SfxPlayer` 정도(비스코프 인접).
- **비스코프**: 적 처치음 · UI 클릭/선택음 (제공 에셋 없음 — 원하면 pick.mp3 재사용)

## BGM (2트랙)
- 인게임 **`bgm.mp3` 루프**.
- **보스 등장(2:00)**: `OnBossSpawned` 구독 → **`boss_bgm.mp3`로 트랙 전환** (간단히 즉시 전환, 여유 있으면 짧은 크로스페이드).
- 결과/타이틀 화면은 인게임 트랙 유지 또는 정지(선택).

## 에셋 체크
- **SFX 6종 + 클리어 징글 + BGM 2트랙** = `_GameKit/Sounds/` 강사 제공, 확보 완료.
