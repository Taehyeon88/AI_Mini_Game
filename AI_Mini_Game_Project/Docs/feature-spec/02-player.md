# 2. 플레이어 (Player)

**기본 스탯**
| 속성 | 초기값 | 비고 |
|------|--------|------|
| HP | 100 | 업그레이드로 증가 가능 |
| 이동 속도 | 7.8 (units/sec) | 업그레이드 가능 |
| 픽업 반경 | 2.3 | EXP gem 자동 흡수 거리 |
| 무적 시간 | 0.5초 | 피격 후 |

**동작**
- 스프라이트: `player.png` 시트(128×64 — §3 슬라이스). **이동 중 2프레임 토글, 정지 시 프레임[0]**
- WASD/방향키 입력 → Rigidbody2D로 이동 (이동만 물리; **전투 판정은 트리거** — convention §6 레이어/충돌)
- **RB2D 설정**: Body Type = Dynamic, **Gravity Scale 0**, **Freeze Rotation Z** (탑다운 — 안 하면 아래로 추락·충돌 시 회전)
- 적과 **트리거** 접촉 시 0.5초마다 데미지 (각 적의 공격력만큼, 물리 밀림 없음)
- HP 0 → 사망 → `GameManager.ChangeState(GameOver)` 직접 호출 (별도 이벤트 없음, convention §4)
- 피격 시 0.1초 빨간 플래시 + 무적 시간 적용 + 짧은 카메라 쉐이크
