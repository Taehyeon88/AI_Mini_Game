# 뱀서류 토이프로젝트 — 게임 기획서

> 강의 섹션 4 토이프로젝트의 source of truth. 13챕터(4-0 prep + 4-1~4-12) 전체 기준.
> 작성일: 2026-05-26 · 변경 시 4-1 Plan 모드 input도 같이 업데이트.

---

## 1. 개요

- **장르**: 탑다운 2D 액션 · 로그라이트 라이트
- **레퍼런스**: Vampire Survivors, 20 Minutes Till Dawn
- **목표**: Claude Code로 한 판 3분짜리 뱀서류 MVP를 13챕터(4-0 prep + 4-1~4-12) 안에 완성
- **플랫폼**: PC (Windows). 키보드 입력. **1080×1920 (9:16, 세로)** 기준 (해상도·화면 상세는 기능명세서 §3)

## 2. 타깃 & 분량

- **수강생 타깃**: Claude Code 입문, 중급 유니티 개발자
- **한 판 길이**: **3분** (시연 최적화 — 강의 영상에서 1회 플레이 풀로 보여줘도 부담 없음)
- **총 콘텐츠 분량**: 단일 스테이지, 2분 잡몹 + 1분 보스전

## 3. 핵심 재미

세 줄로 정의:
1. **밀려오는 적을 도망다니며** 자동 공격으로 정리
2. **죽인 적이 떨군 경험치**를 먹어 레벨업
3. 레벨업 시 **3택 중 하나**로 점점 강해짐 → 후반엔 화면 가득 적도 무난

## 4. 게임 루프

```
시작
 ↓
[메인 루프] 도망 → 자동공격 → 적 처치 → EXP 픽업 → 레벨업 → 3택 → 강해짐 → 다시 도망
 ↓
보스 처치 or 3분 경과 → 클리어 / HP 0 → 게임오버
 ↓
재시작
```

- **마이크로 루프** (초 단위): 이동·자동공격·처치·픽업
- **메조 루프** (30초~1분): 레벨업·3택·강화
- **매크로 루프** (한 판 3분): 보스 처치 클리어 또는 사망

## 5. 진행 단계 (난이도 곡선)

| 시간 | 단계 | 적 종류 | 스폰 빈도 | 비고 |
|------|------|---------|-----------|------|
| 0:00~0:30 | 워밍업 | 쥐만 | 낮음 | 첫 무기로 익히기 |
| 0:30~1:15 | 가속 | 쥐 + 박쥐 | 중간 | 첫 레벨업 1-2회 |
| 1:15~2:00 | 압박 | + 사이클롭스 | 높음 | 빌드 굳히기 |
| 2:00~3:00 | **보스전** | 네크로맨서 + 소환 유령 + 잡몹 | 매우 높음 | 보스 처치 시 클리어 |
| 3:00 (안전망) | 강제 종료 | — | — | 보스 못 잡아도 결과 화면 |

**보스 = 네크로맨서(원거리 캐스터).** 큰 HP(500). 플레이어와 거리를 유지하며 마법탄을 쏘고, 5초마다 유령을 소환. 페이즈 없음. 시연 임팩트(소환 물량)는 챙기되, 마법탄=투사체 풀·소환=스폰 **기존 시스템 재사용**으로 구현 부담 최소.

## 6. 승리·패배

- **승리**: 2:00~3:00 사이에 **보스 처치** → 클리어 화면 (처치 시간, 처치 수, 레벨)
- **타임아웃**: 3분 경과해도 보스 못 잡으면 → 결과 화면 (생존 표시, "다음엔 보스를")
- **패배**: HP 0 → 게임오버 화면 (생존 시간, 처치 수, 레벨)
- **결과 → 재시작** 버튼 한 개

## 7. 톤 & 비주얼

- **그래픽**: 강사 보유 2D 픽셀아트 스프라이트 팩
- **분위기**: 가볍고 빠른 액션 (어둡고 무서운 톤 X)
- **이펙트**: 피격 시 단색 플래시(0.1초), **처치 시 본체 디졸브**(어둡게 틴트 + 스케일 증가 + 0.2~0.3초 페이드아웃 → 소멸. 별도 스프라이트 없이 본체 트윈), 레벨업 시 화면 펄스, 보스 등장·플레이어 피격 시 짧은 카메라 쉐이크
- **사운드**: SFX 6종(공격 2·피격·픽업·레벨업·게임오버) + 클리어 징글 + **BGM 2트랙(인게임·보스)** — 강사 제공 (§10 파일 매핑)

## 8. 명시적 비스코프

토이프로젝트 범위 **밖**(13챕터에서 다루지 않음):
- 다중 스테이지, 다중 보스, 보스 페이즈
- 캐릭터 선택, 도전과제, 메타 진행
- 멀티플레이, 세이브/로드(한 판 단위로 끝)
- 인게임 옵션 메뉴 (음량·해상도 등)
- 모바일 터치 입력 (PC 키보드만)
- 다국어
